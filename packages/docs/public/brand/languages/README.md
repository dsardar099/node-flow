# Language logos

Vendored from [Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons):
`typescript/typescript-original.svg`, `python/python-original.svg`,
`go/go-original.svg`, `java/java-original.svg`, and `rust/rust-original.svg`.

The original SVGs are unmodified. Rust is rendered in white using CSS for
contrast on the dark landing page. The accompanying MIT license is in
`LICENSE.txt`. Logos belong to their respective owners and identify supported
worker languages; their use does not imply endorsement.

HTTP uses a code-native globe/network icon, since it is a protocol rather
than a programming language.
